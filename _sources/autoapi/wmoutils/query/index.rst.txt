.. py:function:: build_base_wdqms_request(module: str, station_type: str, interval: str, category: str) -> str

   Return the string required for a WDQMS API request.

   :Parameters: * **module** (*str*) -- one of ['gbon', 'nwp']
                * **station_type** (*str*) -- one of ['surface','upper-air', 'marine']
                * **interval** (*str*) -- assessment interval, i.e. one of ['monthly', 'daily', 'six_hour'].
                * **category** (*str*) -- one of ['availability', 'quality', 'timeliness']

   :returns: base URL of the API request
   :rtype: str

   .. warning::

      Not all combinations of the above parameters are valid, and the function will raise an error
      if an invalid combination is provided.

.. py:function:: query_wdqms(module: str, station_type: str, interval: str, category: str, var_name: str, date: str, period: str = '00', baseline: str = 'OSCAR') -> polars.DataFrame

   Send a request to WDQMS via its API, and return the reply as a polars.DataFrame.

   :Parameters: * **module** (*str*) -- one of ['gbon', 'nwp']
                * **station_type** (*str*) -- one of ['surface','upper-air', 'marine']
                * **interval** (*str*) -- assessment interval, i.e. one of ['monthly', 'daily', 'six_hour']
                * **category** (*str*) -- one of ['availability', 'quality', 'timeliness']
                * **var_name** (*str*) -- one of ['temperature', 'pressure', 'humidity', 'zonal_wind',
                  'meridional_wind']
                * **date** (*str*) -- date of the availability assessment, e.g. '2023-11'
                * **period** (*str, optional*) -- one of ['00', '06', '12', '18']. Defaults to '00'.
                  No effect unless if interval is 'six_hour'.
                * **baseline** (*str, optional*) -- one of ['OSCAR', 'hourly']. Defaults to 'OSCAR'.
                  No effect unless if module is 'nwp'.

   :returns: the reply from the API request.
   :rtype: polars.DataFrame

   .. rubric:: Examples

   Querying the availability of temperature observations for surface stations in GBON for
   January 2026:
   ```
   query_wdqms(module='gbon', station_type='surface', var_name='temperature',
               interval='monthly', category='availability', date='2026-01')
   ```

   .. todo:: - Allow to query individual centers.


.. py:function:: query_oscar_surface(extra_prms: list | None = None, **search_params: dict) -> polars.DataFrame

   Utility function to query OSCAR/Surface and extract relevant station information.

   :Parameters: * **extra_prms** (*list, optional*) -- list of extra parameters to extract from the API reply in
                  addition to the default ones.
                * **\*\*search_params** -- search keyword-arguments-and-value-pairs, to be fed directly to the
                  'params' keyword of the API requests.get() function.

   :returns:

             containing the 'wigosId', 'Station name', 'longitude', and 'latitude' columns,
                 and any extra parameters specified in the 'extra_prms' argument.
   :rtype: pl.DataFrame

   .. rubric:: Example

   To query a station with a specific wigosId:
   query_oscar_surface(wigosId='0-20000-0-06610')

   To query all fixed surface stations in Switzerland:
   query_oscar_surface(territoryName='CHE',facilityType='LandFixed')

   API Reference:
      https://oscar.wmo.int/surface/#/faq/
